### 4. About the project *(required)*
> *Prompt: A few lines on the problem, who it is for and how you used Wispr Flow.*

```text
I sat down to update my resume and found I couldn't: 21 of 35 achievements in my notes had no measured result because metrics evaporate weeks after shipping. Daybook is a voice-first evening work journal for software engineers. In a 5-minute conversation at the end of the day, it asks the follow-up questions a good manager would ("by how much?"), then files your answers into a searchable memory with resume-ready XYZ bullets ("Accomplished X as measured by Y, by doing Z"). It never invents a number, and each account is sealed with a recovery key only the user holds.

Wispr Flow is both the input to the product and how I built it. Every reflection answer is dictated by voice using Wispr Flow (holding Fn on Mac or using the Flow iOS keyboard). I built the entire application by voice as well—dictating architecture specs, prompts to Claude Code, commit messages, and documentation. When away from my desk, I spoke ideas into Wispr Flow's mobile Scratchpad and Note Taker, handing them over to my coding agent later.
```
